# Privacy Policy for Chrome Controller

**Effective Date:** July 28, 2026

Chrome Controller is a open-source browser extension designed to facilitate local communication between Google Chrome and local AI coding tools via Chrome Native Messaging.

## Data Collection and Privacy Guarantees

1. **No External Data Collection**: Chrome Controller does not collect, track, store, or transmit any user data, browsing history, personal information, or telemetry to external third-party servers.
2. **Local Processing Only**: All browser control actions and DevTools Protocol communications occur strictly on your local machine (`localhost` / Native Messaging IPC).
3. **No Monetization or Tracking**: The extension contains zero tracking scripts, analytics, advertisements, or profiling code.
